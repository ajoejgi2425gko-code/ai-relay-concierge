# AI会議リレー・コンシェルジュ

ChatGPT・Gemini・Copilotの回答を人がコピー＆ペーストでつなぎ、提案・検討・改善・まとめを進めるアプリです。

## GitHub Pagesで公開する手順

1. このZIPをダウンロードし、「すべて展開」します。ZIPそのものはアップロードしません。
2. GitHubにログインし、新しいリポジトリを作ります。
   - Repository name：`ai-relay-concierge`（おすすめ。別の名前でも動作します）
   - Visibility：`Public`
   - 「Add a README file」を有効にすると、作成後にファイルをアップロードしやすくなります。
3. 作成したリポジトリの「Code」画面で「Add file」→「Upload files」を開きます。
4. 展開したファイルのうち、以下の4ファイルをまとめてアップロードします。
   - index.html
   - style.css
   - app.js
   - core.mjs
   **フォルダごとではなく、この4ファイルをリポジトリの一番上に置いてください。**
   README.mdは説明用なのでアップロードしてもしなくても構いません。
5. 「Commit changes」で保存します。
6. リポジトリの「Settings」→「Pages」を開きます。
7. 「Build and deployment」で、以下を選びます。
   - Source：`Deploy from a branch`
   - Branch：`main`
   - Folder：`/ (root)`
8. 「Save」を押して公開処理の完了を待ちます。
9. Pages画面に公開URLと「Visit site」が表示されたら、そこから開きます。

## 公開後の確認

- 「入力例を入れて試す」から依頼文が作れるか。
- 「依頼文をコピー」でコピーできるか。
- 回答を貼り付けて記録すると、次のAIへの依頼文に切り替わるか。
- 元の議題・条件・追加指示・回答が引き継がれているか。
- 「会議を保存」でJSONを取得し、「保存した会議を再開」で復元できるか。
- スマートフォンでも入力・コピーができるか。

ブログには、Pages画面で確認した公開URLへのリンクやボタンを設置してください。このZIPを用意した時点では、GitHub側へのアップロード・一般公開はまだ実施していません。

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| index.html | アプリ画面 |
| style.css | 画面のデザイン・スマホ対応 |
| app.js | コピー、画面操作、会議の保存・復元 |
| core.mjs | 依頼文生成、AIの担当切り替え、データ検証 |

4ファイルは同じ場所に置いてください。ビルド、npm、サーバー設定、APIキーは不要です。相対パスで参照するので、リポジトリ名が変わっても動作します。index.htmlをPC上で直接開くと、ブラウザのモジュール制限で動かない場合があります。公開後のHTTPSのURLで確認してください。

## 利用・保存

- 外部AIへの送信と回答の取り込みは、利用者自身がコピペで行います。
- このアプリはAI APIを呼び出しません。外部AIの利用は各サービスの料金・無料枠・利用上限に従います。
- 会議内容のサーバー送信、アクセス解析、広告、外部スクリプトは実装していません。
- 会議は自動保存しません。ページを閉じる・更新する前に「会議を保存」を押してください。
- 保存したJSONには議題・条件・依頼文・AIの回答・下書きが含まれます。公開リポジトリに会議ファイルをアップロードしないでください。
- 1つの会議は20発言まで。長い依頼文は外部AIの入力上限に達する場合があります。
- AI同士の合意は、回答の正確さを保証しません。

## 更新する場合

変更したファイルを同じリポジトリの同じ場所へアップロードし、Commitします。公開設定が維持されていればPagesが更新されます。古い表示のままの場合は、公開処理の完了を確認してからページを再読み込みしてください。

## PWA対応版（2026年11月14日）

以前の版にはPWAの設定がなかったため追加しました。今回はZIPをすべて展開して、README以外の11ファイルを、既存のAI会議リレーのリポジトリの一番上へまとめて追加・上書きしてください。フォルダごとやZIPのままアップロードしないでください。元の4ファイルだけの更新ではインストール設定は反映されません。

アップロードするファイル：index.html、style.css、app.js、core.mjs、pwa.js、sw.js、manifest.webmanifest、icon.svg、icon-192.png、icon-512.png、apple-touch-icon.png。

※教材選定コンシェルジュのリポジトリではなく、AI会議リレーのリポジトリへ配置してください。

公開処理が完了したらGitHub PagesのHTTPSの公開URLを開き直します。「ホーム画面への追加方法」または「アプリをインストール」ボタンを使用してください。Android Chromeは︙メニュー、iPhone Safariは共有メニューからホーム画面へ追加できます。自動インストールボタンの表示はブラウザ側の判定に依存します。

初回オンライン表示後にアプリのファイルをキャッシュします。依頼文作成・会議ファイルの読み込みなどはオフラインでも動作するようにしましたが、外部AIの利用には通信が必要です。会議内容の自動保存は追加していません。閉じる前に会議ファイルを保存してください。

キャッシュはリポジトリの公開パスごとに分け、同じgithub.io上の他アプリのキャッシュを削除しない仕様です。更新時は作業中の会議を保存してアプリの全タブ・ウィンドウを閉じ、開き直してください。

動作確認：PWA案内の画面表示、ファイル参照・アイコン寸法、オフライン応答とキャッシュ削除範囲の模擬テスト。利用者の端末でのインストール完了は公開後に確認が必要です。
